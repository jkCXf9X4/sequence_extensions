# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it by
opening a GitHub issue at:

https://github.com/jkCXf9X4/sequence_extensions/issues

Please include as much detail as possible to help us reproduce and understand
the issue:

- The affected version(s) of the package.
- A description of the vulnerability and its impact.
- Steps to reproduce, including any relevant code or configuration.
- (If known) a suggested fix or mitigation.

We will acknowledge your report and work to address it as soon as possible.
Please do not disclose the vulnerability publicly until it has been resolved.
